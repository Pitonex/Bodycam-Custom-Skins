## Короткая инструкция по установке мода на скины(пока 2 шт):

Скачивается [архив](https://github.com/Pitonex/Bodycam-Custom-Skins/releases/download/beta/mods.zip).
Распаковываем.
Заходим в steam.

В библиотеке находим Bodycam, нажимаем правой кнопкой мыши, выбираем "свойства".
![](screenshots/Game_.png)

Нажимаете "установленные файлы".
![](screenshots/_.png)

Нажимаете "обзор", должна открыться папка с игрой.
![](screenshots/Game_File.png)

Открываете "Bodycam" -> "Content" -> "Paks"
Закидываете распакованный архив в папку.
Переименовываем папку из "mods" в "~mods".
(в Paks должна быть папка ~mods с файлами заканчивающихся на .pak, .ucas, .utoc.)
![](screenshots/Goodfiles.png)

ВСЁ! Можно запускать игру!
